The index is a weighted composite — certification 40, capital 25, organisation 20, structure 15. The certificate carries the most because no amount of capital substitutes for it. A module you have not opened counts as zero, deliberately: an unanswered question is not a passed one. The Revenue Model Builder reports below but is not scored here — it was added after this index was set, and a tool added later should not move a number you have already been given.

Critical path

Working back from the certificate

The five phases scheduled against your sector's indicative lead band. The date that matters is the first one — the day you must be at the pre-application meeting for the target to survive.

Scenarios

Model more than one future

Each tool holds one model, so testing an alternative used to mean destroying the answer you had. Save the workspace as a named scenario first — two aircraft or three, leased or owned, HoldCo or three-tier — then compare them side by side and restore whichever you want to work on.

Your workspace

Take it with you

There is no account here, and that is the point — but "no account" must not mean one cleared browser costs you months of work. Export writes the whole workspace to a file you save. Import reads one back, on this device or another, or from a colleague working the same venture.

The file never leaves your device unless you send it Exporting writes to your downloads folder. Importing replaces the saved state of every tool the file covers, so export your current work first if you want to keep it.
