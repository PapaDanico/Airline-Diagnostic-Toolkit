Compare like with like, then against revenue

Short sectors carry more take-offs and turnarounds per kilometre, so a short-haul carrier's CASK looks worse than a long-haul one's for the same efficiency. Adjust to a common stage length before comparing, then set the cost against what each seat-kilometre earns.

The adjustment scales CASK by the square root of stage length relative to the comparison length. That exponent is a common analysts' rule of thumb, not a sourced constant; use it to put two carriers on one footing, not as a precise correction.
